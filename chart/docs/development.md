# Development Guide

## Prerequisites

- Helm 3
- kubectl
- Access to a Kubernetes cluster
- Container registry with Ainsel images

## Chart Structure

```
ainsel/
  Chart.yaml          # Chart metadata
  values.yaml         # Default values
  crds/               # CRD definitions (applied before templates)
    agent.yaml
    agentimage.yaml
    webhookconnector.yaml
  templates/
    _helpers.tpl       # Template helpers
    namespace.yaml     # Namespace resource
    agent-operator/    # Agent operator deployment + RBAC
    connector-operator/ # Connector operator deployment + RBAC
    hub/               # Hub deployment + service + ingress + RBAC
    ui/                # UI deployment + service
    qdrant/            # Qdrant statefulset + service + PVC
```

## Template Rendering

```bash
# Render templates without installing
helm template ainsel . -n ainsel -f values.yaml

# Render with custom values
helm template ainsel . -n ainsel -f values.yaml --set hub.image.tag=v1.0.0

# Dry run install
helm install ainsel . -n ainsel --dry-run
```

## Linting

```bash
helm lint .
```

## Installing

```bash
# Create namespace and install
helm install ainsel . -n ainsel --create-namespace

# With custom values file
helm install ainsel . -n ainsel -f my-values.yaml
```

## Upgrading

```bash
helm upgrade ainsel . -n ainsel -f values.yaml
```

## Updating CRDs

CRDs in `crds/` are generated by the operator projects:

1. Run `make manifests` in ainsel-k8s-ai-agent-operator
2. Run `make manifests` in ainsel-k8s-event-source-gateway-operator
3. Copy generated CRDs to `crds/`
4. Helm does not update CRDs on `helm upgrade` -- apply manually:
   ```bash
   kubectl apply -f crds/
   ```

## Adding a New Component

1. Create a new directory under `templates/<component>/`
2. Add deployment, service, RBAC templates
3. Add values to `values.yaml`
4. Update `_helpers.tpl` if needed
5. Test with `helm template`
