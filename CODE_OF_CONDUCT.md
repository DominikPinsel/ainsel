# Code of Conduct

## Our Commitment

AInsel is a technical project maintained by a small team. We want it to be a
place where anyone can contribute regardless of background or experience level.

## Expected behaviour

- Be respectful and assume good faith.
- Keep criticism focused on code and design, not on people.
- Accept constructive feedback gracefully — and give it the same way.
- Step back from heated discussions and revisit them when the temperature drops.

## Unacceptable behaviour

- Personal attacks, insults, or harassment of any kind.
- Discriminatory language or behaviour based on background, identity, or
  experience level.
- Sustained disruption of discussions or deliberate bad-faith participation.

## Enforcement

Violations can be reported by contacting the maintainers directly via a private
Forgejo message or by emailing the address listed in the repository profile.
Reports will be handled confidentially. Maintainers reserve the right to remove
comments, close threads, or restrict participation for conduct that violates
these guidelines.

## Scope

This Code of Conduct applies to all project spaces: issues, pull requests,
discussions, and any other venue where people interact around this project.
